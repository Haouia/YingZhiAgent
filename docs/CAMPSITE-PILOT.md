# 六城营地查询试点评测

本轮检验现有服务器的地点查询，不修改业务逻辑。30 个命名样本在首次查询前冻结，另做六城各一次「露营地」泛查。通过门槛为命名 Hit@5 至少 26/30、泛查准确率至少 90%，并且六城都有至少一个可核实结果。未通过时先修复检索缺口，不扩展成全国覆盖结论。

## 文件与数据流

| 文件 | 作用 |
| --- | --- |
| `data/evaluation/campsite-pilot-v1.json` | 30 个独立样本、区县和地址、预登记别名、公开来源、核对日期及判分规则；不含高德 POI 结果 |
| `scripts/evaluate-campsite-pilot.py` | Python 3.12 标准库脚本；collect 通过已登录应用接口串行采集，score 根据逐候选复核表计算结果 |
| `tests/test_campsite_pilot.py` | 验证失败不剔除、待复核不能通过、错市不能通过、重复和缺失评审被拒绝、五个同题候选只算一次命中 |
| `.local/campsite-pilot/pilot-v1-initial/` | 本次私有证据：freeze.json、health.json、results.jsonl、review.csv、run.json、summary.json；凭证不入文件 |
| `docs/CAMPSITE-PILOT-RESULTS.md` | 本次结果、逐题结论、问题优先级和下一步门槛 |

流程：独立来源 → 固定样本与规则 → freeze.json 记录 SHA256 → 应用登录 → 搜索 → 在下次搜索前逐一取详情 → 每个候选填写复核表 → 校验完整性和文件哈希 → 计算结果。

评测不增加新依赖、不操作预约或工单，不将地点资料写入规则知识库。凭证仅从私有 `.local/server-deploy/server.env` 的 DEMO_PASSWORD 读取，使用 user2 账号，令牌只放内存。需要已配置的服务器 SSH 隧道 `127.0.0.1:18090`。脚本不会将凭证发往其他主机。

## 采样和判分

- 六城各五个，覆盖城区与郊区、森林、房车、湖畔、滨海、田园等类型。每城五个仍是目的性小样本，不能推断全国营地总覆盖率，也不是统计代表性抽样。
- 名称和地点证据来自政府、文旅部门及当地媒体原创/发布账号，不使用本次高德结果反选样本。首次查询使用来源完整名称；不自动缩短名称或补词，不使用重试掩盖失败。
- 名称标点、英文大小写、描述顺序变化需结合独特品牌、区县与独立地址判断；不能只靠模糊相似度。不同经营者、邻接营地或园区里的充电站不能算同一营地。预登记别名之外，若仍需新证据才能建立身份，标明补充证据，无法确定则 uncertain。
- 泛查每个展示候选均复核同城和营地身份；全部展示候选进入分母。空结果单列，详情失败或无独立证据不能计入有效结果。餐饮、购物、充电站、服务中心、出入口等不因名称包含「营地」就通过。
- 决策为 valid、invalid 或 uncertain，均要填写理由和证据链接。uncertain 保留在泛查分母，不计命名命中。不自动将 HTTP 200 视为正确。
- 30 个命名查询的超时、限流、空结果仍在分母内。应用搜索时延以 36 次全部请求计算最近秩 P50/P95，包含失败；详情耗时另存。采集请求之间等待 1.5 秒，等待不算接口时延。该串行结果不是并发能力或真实对话性能结论。

## 复跑步骤

在 PowerShell 中从 `D:\camp-agent` 执行，使用新的运行目录；脚本拒绝覆盖旧目录：

```powershell
python -m unittest discover -s tests -p test_campsite_pilot.py -v
python scripts/evaluate-campsite-pilot.py collect --run .local/campsite-pilot/pilot-v1-rerun --release release-20261109-172651
```

打开新目录的 review.csv，逐行核对候选名称、地址、详情、独立来源，填写 decision、reason、evidence_url，再执行：

```powershell
python scripts/evaluate-campsite-pilot.py score --run .local/campsite-pilot/pilot-v1-rerun
```

score 会拒绝修改过的样本/结果、查询缺失、重复评审、未填写评审或把错误城市/失败详情标为 valid。完整评审后即使不达标也输出 summary.json，以 passed 字段判断结果。该工具依赖人工证据核对，不能验证网页真伪或代替二人复核。

## 证据与限制

来源发布跨度 2022–2026 年。CD05、HRB05、GZ01 等页面抓取超时，核对使用搜索索引中可见的发布者、名称和地址，数据中保留 access 标记；不是已成功归档的网页。来源旧或季节性经营不会被描述为当前仍营业。UR 来源页面日期与文中日期有差异，原样记录。

当前证据只支持「公开资料所列营地身份及位置」与「本次系统能否查到」；不验证营业、余位、报价、宠物、明火、预订或投诉处理。查询账号和服务配额按现有配置使用，应用搜索/详情请求数不等于供应商计费数。

应用不增加批量 POI 数据库或原始 MCP 响应留存。仅在 `.local` 保存本次必要的候选 ID、名称、地址、城市、类别、状态和耗时以供判分，文件不进版本库，不上传公开数据集，不作为营地经营数据库；复核后按账号授权和保留策略清理。公开报告提供汇总、命名样本判定及来源，不发布批量泛查候选明细。

修复后仍使用 v1 冻结样本复测，但该集合自本轮起已是开发回归集。全国 155 个命名样本须重新独立收集并在调参前冻结，不能用已看过的 v1 成绩充当独立全国验收。
