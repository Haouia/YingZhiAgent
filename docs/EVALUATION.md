# DeepSeek 与 BM25 评测记录

日期：2026-11-05。

## 2026-11-05 本机基线

以当前后端 JAR 启动独立进程，在临时 H2 库里发布并核对 5 座虚构营地的 60 份公开资料和 1 份客服资料。检索调用正式 Java `Retrieval.search`，对话通过 HTTP 调用正式 `/api/chat`，使用 DeepSeek `deepseek-flash` 和 BM25 关键词检索。应用库原有发布状态保持独立。

运行前固定 94 条用例。60 条模板问题覆盖每份公开资料，26 条口语或复杂题含跨营地对比、对话指代和伪造引用指令，8 条测试缺少依据或权限不足。34 条用例跑真实对话，其中两条多轮用例各有一条前置请求，共 36 次 HTTP 对话请求。每题单次执行，由评测助手逐条对照原文判分。

### 检索

Hit@5 表示前 5 条至少命中一份预先标注的资料。限定营地的检索使用用例中的营地 ID，跨营地对比不限制营地，多轮用例使用写明营地的改写。全库检索保留同样的题干和普通用户权限。8 条边界题不计入 Hit@5。

| 有标准证据的问题 | 限定营地 Hit@1 | 限定营地 Hit@5 | 全库 Hit@1 | 全库 Hit@5 |
| --- | ---: | ---: | ---: | ---: |
| 60 条模板题 | 55/60（91.7%） | 60/60（100%） | 60/60（100%） | 60/60（100%） |
| 26 条口语与复杂题 | 18/26（69.2%） | 22/26（84.6%） | 18/26（69.2%） | 24/26（92.3%） |
| 86 条合计 | 73/86（84.9%） | 82/86（95.3%） | 78/86（90.7%） | 84/86（97.7%） |

口语与复杂题在限定营地后低于计划的 90% Hit@5 目标。漏掉的题目涉及「提前三天退掉」「狗狗满营地跑」「中午一点撤营」「能不能让狗一起去」。这些问法与文档中的「取消」「宠物」「离场」用词不同。全库检索仍漏掉退订和离场两题。真实对话的工具调用在本次四题里都找到了正确资料，因此应分别读检索基线和对话结果。

### 真实对话

| 检查项 | 结果 |
| --- | --- |
| 知识题核心事实正确 | 26/26 |
| 知识题正确且标注资料均有正文引用 | 24/26（92.3%） |
| 缺少依据或权限不足时正确处理 | 7/8（87.5%） |
| 多轮指代到正确营地且引用规则 | 2/2 |
| 真实对话用例返回 HTTP 200 | 33/34 |
| 完整回答耗时 P50 / P95 | 3.81 秒 / 4.40 秒 |
| 完整回答耗时 ≤3 秒 | 6/34（17.6%） |

耗时从本机发出请求到收到完整响应，34 条计分用例均纳入统计，包含 1 条错误响应，排除 2 条前置请求。分位数采用最近秩法。知识题有 2 条核心事实正确但只有结构化工具数据，未给文档引用。30 条带正文引用的回答中，按每条回答去重后的 58 个引用均匹配当次召回、当前发布版本及公开权限。跨营地宠物规则引用覆盖两份标准资料。

| 用例 | 发现 |
| --- | --- |
| K03 青岚竹溪演示价格、K18 白沙听潮淋浴设施 | 结构化查询给出正确事实，正文未引用收费或设施资料。 |
| B07 未收录的蓝港环岛营地 | HTTP 502，报「模型未提供证据引用，请重试」。单独跑 BM25 可复现该问题有候选但无对应营地的标准资料。后端当前只要收到候选，就要求模型给出引用。 |
| B03、B04、B05 会员积分、救生衣、年卡 | 模型正确说明缺少依据，但附带了与目标问题关系弱的收费、设施或退改资料。 |
| B08 内部手册、K24 伪造引用指令 | 未泄露内部标识，未使用虚构引用。独立权限检查中，客服能命中手册，普通用户检索不到，直接访问原文返回 404。 |

本轮临时库写入 0 张正式工单、0 个草稿。原始输出、预期和判分均可逐题核查。36 次是应用 HTTP 对话请求数，模型工具循环会产生额外上游调用，本轮未记录上游调用次数、token 或账单。

### 复现

在项目根目录用 Java 21 和 PowerShell 运行。脚本使用现成的后端 JAR，并记录固定用例和 JAR 的哈希、资料版本及逐题结果。真实模型单次采样会有波动，当前基线使用虚构资料和本机串行负载。

```powershell
./scripts/evaluate-keyword.ps1        # 只测 BM25 与权限
./scripts/evaluate-keyword.ps1 -Live  # 另跑 36 次对话请求，使用私有 .env 的 DeepSeek Key
```
