# 固定演示流程

所有名称、价格和规则均为虚构演示。

## 用户查询与引用

1. 使用 user 登录。
2. 发送“找一个杭州附近、有洗手间的营地”，查看工具摘要和查询结果。
3. 继续发送“第二个怎么预订”，检查会话指代和原文引用。
4. 点击引用卡片，查看资料位置及原文。
5. 问未来日期的余位，检查回答不承诺真实库存与预订成功。

本地 demo 只验证确定性业务路由和关键词原文检索，不代表语义理解、向量检索或云模型质量。

## 工单与客服

1. user 发送“投诉青岚竹溪营地：停车区域标识不清晰，请整理工单”。
2. 核对草稿；未点击确认时，正式工单列表不能出现该记录。
3. 点击确认，重复操作不能创建重复工单。
4. “我的工单”查看待处理状态。
5. 退出，staff 登录；进入客服工作台，将状态变为处理中，填写公开说明。
6. 再变为已解决并填写结果。
7. user 重新登录，在工单详情中查看进度和回复。
8. user2 不能通过复制 ID 查看 user 的工单、会话或草稿。

## 运营资料与版本

1. ops 登录，查看知识资料，预览源文与当前版本。
2. 上传 UTF-8 Markdown/TXT 或 PDF/DOCX，刷新直到 REVIEW。
3. 核对提取内容后点击发布。
4. 同一逻辑资料使用“新版本”上传；新版本未发布前，旧版本继续生效。
5. 下架资料后，新问答不再引用；旧会话引用标为历史版本。
6. 内部资料只对工作人员开放；普通用户不能通过引用 ID 读取。
7. 编辑营地结构化字段，下次查询读取最新数据。
