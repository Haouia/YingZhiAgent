## 验收中修复的问题

当模型先检索规则但没有引用，随后成功创建投诉草稿时，`ChatService.generate` 原先仍用通用“未找到规则资料”覆盖回复。新增回归用例先复现失败，再在现有输出校验后为已生成草稿返回确认提示。引用检查及正式工单确认规则保留。

新增 `DeepSeekKeywordTest.complaintDraftIsAcknowledgedWhenRuleSearchHasNoEvidence`，验证草稿为 PENDING、提示核对确认、没有自动生成正式工单。修复后 37 项默认后端测试通过，JAR 打包成功，服务器真实投诉请求返回正确提示。原 8 项 MySQL/Qdrant 集成测试在当日 15:25 已通过；本次一行回复修复后没有重复运行该组测试，不把旧结果计为本轮新执行结果。
